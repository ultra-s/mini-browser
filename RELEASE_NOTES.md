## v1.1.0 — user data + polish

- Signed APK (fixes install failure on phones)
- Bookmarks, history, reading list — tap to revisit
- Session restore: tabs come back after closing the app
- Search engine picker: DuckDuckGo / Google / Bing / Brave
- Export all data to Downloads/mini-export.json; Wipe all data
- Stealth mode: nothing is ever written to disk
- Autofit edge-to-edge UI, runtime permission requests (camera, mic, downloads, notifications)
